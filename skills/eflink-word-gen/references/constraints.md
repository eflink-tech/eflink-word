# 硬约束（违反会导致导入失败或版式错乱）

## 1. 换行规则

- 正文每一段以 `\n` 结束（转换器自动补）；不要手动在 text 末尾写 `\n`。
- 标题元素的外层 `value` 与 `valueList[].value` 都要带换行——转换器已处理，spec 里只写纯文字。
- 空白间距用 `{"type":"spacer","lines":1}` 或空段落，不要连写多个 `\n` 字符串。

## 2. 列表

- 一个 `list` 块 = 一组连续列表项；不同列表之间不要合并（编号会串）。
- 每项是独立的一行，项内软换行会被标记 `listWrap`，不会拆成新编号。
- `ordered: true` 配 `style: "decimal"`；无序用 `disc/circle/square`；待办清单用 `checkbox`
  （编辑器里可点击勾选，**不要**写字面 "☑"）。
- 多级列表用 `items[].level`（0 起），不要嵌套 list 块。

## 3. 表格

- 单元格内容不带 `\n`（转换器不会补），一个单元格内多段请用 `runs` 或拆行。
- `colWidths` 之和不要超过正文宽度（A4 默认页边距下约 554px）；超宽会溢出页面。
- 合并单元格用 `colspan/rowspan`，被合并位置不要重复写占位单元格——行内单元格数量
  应等于真实占位后的逻辑列数。
- 表头重复打印：给行加 `"repeatHeader": true`。

## 4. 图片

- 图片必须是本地文件路径（相对 spec 文件）或 `data:image/...;base64,...`；外链 http 图片
  需要编辑器联网加载，转换器会警告。
- 宽高单位 px，务必显式给 `width` 和 `height`；只给宽度时转换器按 2:3 估算高度并警告。

## 5. 页面与字体

- 页面尺寸/页边距只影响 HTML 预览；`.efw.json` 导入只恢复正文/页眉/页脚，纸张设置沿用编辑器当前配置。
- 字号单位 px；正文 16，标题 32/24/19/17/15/14（level 1~6）。
- 颜色写 `#RRGGBB`；高亮 `highlight` 同理。Word 的“高亮”是不透明色块。
- 字体名用系统字体（Microsoft YaHei / SimSun / KaiTi / Arial 等），不要写字体栈。

## 6. 文字纪律

- 不要把 HTML 标签、Markdown 语法（`**`、`#`）写进 text；样式用字段表达。
- 截图识别时水印/页码/广告字样忽略；正文按阅读顺序逐段转录。
- 生成公文/合同类文档时，占位符统一用 `××` 或 `__________`，日期写具体年月日。

## 7. 自检必须做

转换产出 `.html` → Chrome headless 截 PNG → Read 检查：
- 标题层级与字号、段落缩进、对齐
- 表格边框/合并/底色/列宽是否与原图或预期一致
- 列表编号连续、复选框状态正确
- 页眉页脚出现在每页正确位置、文字无截断
发现问题改 spec 重转，别交付没自检过的产物。
